How this is counted

The web addresses in the report texts, tied to the library where they point into it. {{ totals.reports }} of {{ n_reports }} reports contain addresses ({{ "{:,}".format(totals.links) }} different ones in all, on {{ "{:,}".format(totals.hosts) }} hosts). An address counts once per report. It points to a report of the library when it is that report's address (case, "www." and a trailing slash ignored), to another agency when it lies on the site of one other source of the library (the host of its home page; where the home page is deeper in a shared portal like gov.uk, only that path; a host two sources share is not guessed at; a report linking to its own agency's site is left out), and otherwise to an outside source. Addresses broken across lines in a PDF are not recovered, so every count is a minimum. Each number links to the reports it counts.
