How this is counted

What the official sources say about the terrorism threat level of {{ countries|length }} states – {{ n }} statements, {{ confirmed }} confirmed against their source{% if checked %} (announcement pages last checked {{ checked }}){% endif %}. Two kinds: announcement – the official notice of a change (UK MI5; page re-checked by fetch-threat-levels), and report – a level that an agency's report in this library states; the quote is checked against the library's stored text every time. A report shows the level at that time: not when it began, and not a complete history. The scales differ between states (a "3" in Belgium's four steps is not a "3" in the Netherlands' five), so levels are shown on each state's own scale and never ranked across states. The list is hand-curated and short; the states that do not publish a level are not here.
