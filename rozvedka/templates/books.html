How books are read
  • Put PDFs and EPUBs into {{ folder }} and run python -m rozvedka import-books. Each file is copied into the library; the original stays where it is. Encrypted (DRM) files cannot be read and are listed by the import.
  • Metadata, in this order: books.yaml in that folder, written by hand (- {file: …, title: …, authors: [...], publisher: …, year: …, isbn: …}); Open Library by ISBN (CC0), which also links authors to Wikidata; the EPUB's or PDF's own metadata. The ISBN comes from the EPUB metadata or the copyright page (check digit verified). Every field below says where it came from.
  • A book is a secondary source as of its publication year. It is of the document type "Book" – choose that type on Documents to search them. A publishing house is a source of the kind "book" (▲).
  • Book text stays on this machine: the dataset export leaves book files and text out. Pages show passages, never the whole text.
