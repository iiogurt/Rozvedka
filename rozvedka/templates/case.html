How this works

Pin up to {{ b.max }} entities here or with 📌 Pin on an actor, entity, Rings or Find a connection page. There is one board for the whole portal, kept in {{ b.file }}. That file is never committed and only personal backups carry it, because a case file says what you are looking into. For every pair the board finds the most specific chain, as Find a connection does: official lists count most, co-mentions least, and hubs and common tools are weighed down. The pair grid shows how many steps each chain has, and each number opens all the chains of that pair. Connectors are entities that sit on the chains of several pairs; they are often the thread to pull, but a chain is a set of stated links, not a finding. The export lists the pins, the notes, every chain with a citation for each step, and the connectors.
