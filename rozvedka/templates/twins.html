Toolkit twins

Threat groups that work alike: of {{ groups }} groups in MITRE ATT&CK, the pairs whose techniques and software overlap most – rare items weighted up, so sharing a custom implant counts and sharing “PowerShell” hardly does.

How this is counted

Each group's toolkit is what MITRE ATT&CK{% if meta %} (catalog {{ meta.versions.get('enterprise-attack') }}, retrieved {{ meta.retrieved }}){% endif %} lists as its techniques and its software. An item's weight is log(groups ÷ groups using it). The score is the weight of what two groups share divided by the weight of everything either uses – 1.0 for identical toolkits, 0 for nothing in common. Pairs sharing at least {{ min_shared }} items are listed. A similar toolkit is a lead, not a link: groups copy each other, buy the same tools and are described by the same vendors; stated links are on the Network page. Each pair's numbers open the items it shares.
